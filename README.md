# 📒 我的错题本

给孩子用的错题整理工具：**手机拍照录入错题 → 弹出页面填写答案和错因 → 按科目、类别整理 → 定期复习**。

这是一个 PWA 网页应用。不用上架应用商店，用手机浏览器打开后「添加到主屏幕」，用起来和 App 一样，断网也能打开。

## 功能

| 功能 | 说明 |
| --- | --- |
| 📷 拍照录入 | 点「拍错题」直接调起后置摄像头，照片会自动压缩（约 200~400KB 一张） |
| 📝 录入弹窗 | 拍完自动弹出：选科目、选类别、写正确答案（可再拍一张答案图）、我当时的答案、错因（可多选 + 自由描述）、知识点 |
| 📚 科目 | 默认语文 / 数学 / 英语 / 物理 / 化学，可在设置里增删改 |
| 🗂 类别 | 每个科目有自己的类别，默认：课本 / 练习册 / 作业 / 试卷 / 其他，可单独增删、排序（比如数学加「期中考试」） |
| 🔍 筛选 | 顶部按科目 → 类别两级筛选，再按「未掌握 / 全部 / 已掌握」过滤 |
| 🔁 复习 | 每轮抽 10 道未掌握的题（复习次数少、隔得久的优先），先看题自己重做，再翻答案；**连续做对 3 次自动标记为已掌握** |
| 📊 统计 | 各科错题数、最常见的错因排行，帮你发现孩子的薄弱环节 |
| 💾 备份 | 导出 / 导入 JSON 备份文件（含图片），可以存到微信、网盘，换手机时恢复 |

## 怎么用到手机上

数据只保存在手机本地（浏览器的 IndexedDB），不上传任何服务器，所以只需要一个能访问到这些文件的网址。

### 方法一：GitHub Pages（推荐，免费）

1. 把本分支合并到 `main`
2. 打开仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`，保存
3. 一两分钟后会得到网址：`https://<你的用户名>.github.io/new1/`
4. 用手机打开这个网址：
   - **iPhone**：用 Safari 打开 → 点底部「分享」→「添加到主屏幕」
   - **安卓**：用 Chrome / Edge 打开 → 菜单 →「添加到主屏幕 / 安装应用」

> 注意：摄像头和离线功能要求 HTTPS，GitHub Pages 自带 HTTPS。
> 在国内访问 github.io 如果比较慢，可以把这几个文件放到 Gitee Pages、Vercel、Netlify 或任何静态托管上，方法相同。

### 方法二：电脑上本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## ⚠️ 数据安全提醒

- 数据只在**当前手机、当前浏览器**里。换手机、卸载浏览器或清除网站数据之前，请先在「设置 → 导出备份」。
- 建议每隔一两周导出一次备份，存到微信「文件传输助手」或网盘。
- iPhone 上要从**主屏幕图标**打开，不要只在 Safari 里打开，否则长期不用时 Safari 可能会清掉数据。

## 后续可以扩展的方向

参考了市面上错题 App 的常见设计（题干 / 错解 / 正解三段式、错因关联知识点、复习计划、组卷打印），以后可以考虑：

- **去除手写痕迹 / OCR 识别题目文字**：可接入百度、腾讯云等 OCR 接口
- **错题组卷打印**：选几道错题排版成 PDF，打印出来让孩子重做
- **艾宾浩斯复习提醒**：按 1、2、4、7、15 天的间隔推送复习
- **多设备同步 / 家长端**：需要后端（如微信云开发、Supabase）
- **改做微信小程序**：用 `wx.chooseMedia` 拍照 + 云开发数据库存储，数据结构可以沿用本项目
