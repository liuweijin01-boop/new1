# 沙城突击

CS（反恐精英）风格的 3D 第一人称射击网页游戏。用浏览器打开 `index.html` 即可游玩（需要联网加载 three.js）。

- 地图：沙城风格场景，有建筑、隔墙、矮墙和可跳上去的木箱，A / B 包点
- 敌人：方块人恐怖分子，会巡逻、听到枪声会搜过来、发现你后会扫射和横移
- 回合制：清除全部敌人进入下一回合，敌人数量、反应速度和枪法逐回合提升
- 武器：AK-47，30 发弹匣，有后坐力和扩散；爆头一枪毙命，击杀补充 10 发备弹

## 操作

| 按键 | 作用 |
|---|---|
| W A S D | 移动 |
| 鼠标 / 左键 | 瞄准 / 开火（按住连发） |
| R | 换弹 |
| 空格 | 跳跃 |
| C | 蹲下（更准） |
| Shift | 静步 |
| Esc | 暂停 |

手机上：左侧拖动移动，右侧滑动瞄准，右侧按钮开火、换弹、跳、蹲。
