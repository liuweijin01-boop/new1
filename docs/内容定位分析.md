# 做哪类内容更合适？

> 我目前还不了解你的职业、经历和目标，所以这里先给出**判断框架 + 适配度排序**。填好 `profile.md`，或在 Claude Code 里说「帮我做账号定位」，就能得到针对你本人的结论。

## 1. 先认清一个现实：AI 能放大你，但替代不了你

两个平台都在打击同质化的 AI 内容：小红书限流「搬运、无个人体验」的笔记，公众号的推荐流也偏向原创与互动。所以选方向时最重要的一条是：

**选「你有真实经历/专业判断 + AI 负责结构化、排版和提效」的方向，不选「AI 从零编」的方向。**

## 2. 两个平台的角色不同

| | 小红书 | 公众号 |
|---|---|---|
| 流量来源 | 推荐 + **搜索**（很多人把它当搜索引擎） | 订阅 + 推荐 + 朋友圈转发 |
| 最受欢迎的形式 | 6–9 页**知识卡片**、清单、对比、教程 | 1500–3000 字深度长文、经验复盘、观点 |
| 核心指标 | **收藏**（说明有干货）、评论 | 读完率、转发、关注 |
| 作用 | 涨粉、获客的「前门」 | 沉淀信任、承接转化的「客厅」 |

最省力的组合：**写一篇公众号长文 → 拆成小红书卡片**。本仓库的流水线就是按这个设计的。

## 3. 内容类型 × AI 工作流适配度

| 内容类型 | AI 适配度 | 涨粉潜力 | 门槛 / 风险 | 说明 |
|---|---|---|---|---|
| **职业经验 / 行业干货**（求职、面试、职场技能、某行业入门） | ⭐⭐⭐⭐⭐ | 高 | 需要真实从业经历 | 最推荐。卡片化天然合适，收藏率高，变现路径清楚（咨询、课程、内推） |
| **AI 工具 / 效率方法论**（工具测评、工作流、提示词） | ⭐⭐⭐⭐⭐ | 高 | 赛道拥挤，要有差异化 | 你本身在用 AI 搭工作流，这就是现成素材。建议「AI + 你的行业」做垂直，例如「AI + 财务」「AI + 教师备课」 |
| **学习 / 读书笔记、知识科普** | ⭐⭐⭐⭐ | 中 | 低 | AI 擅长提炼结构；靠持续输出取胜，适合打基础 |
| **攻略清单**（考证、留学、城市生活、办事流程） | ⭐⭐⭐⭐ | 中高 | 信息必须准确、及时 | 搜索流量大；AI 做整理，你负责核实 |
| **个人成长 / 副业记录**（真实过程、数据复盘） | ⭐⭐⭐ | 中 | 需要持续真实进展 | 人设强、粘性高；AI 只能帮排版，内容得靠你 |
| **行业资讯解读** | ⭐⭐⭐ | 中 | 时效性强、需要判断力 | 公众号更合适；小红书做「一图看懂」 |
| 情感 / 鸡汤 / 泛泛励志 | ⭐⭐ | 低 | AI 味重，极易同质化 | 不推荐 |
| 美妆、穿搭、探店、美食 | ⭐ | 高 | 依赖实拍 | AI 帮不上核心环节（照片），除非你本来就在拍 |
| 医疗、投资理财建议 | ⭐ | — | 平台要求资质，违规风险高 | 没有资质别碰；可做「个人记账/理财习惯」这类非建议内容 |

## 4. 给你的选择方法（15 分钟）

1. 写下 3–5 个候选方向：**你的工作领域**、**你花钱/时间最多的爱好**、**别人常来问你的事**。
2. 每个方向按 5 个维度打 1–5 分：

   | 维度 | 权重 | 问自己 |
   |---|---|---|
   | 个人优势 | 30% | 我在这件事上比 80% 的人懂吗？有成果吗？ |
   | 读者需求 | 25% | 小红书搜这个关键词，头部笔记收藏过千吗？ |
   | 可持续性 | 20% | 我能不靠查资料连写 30 篇吗？ |
   | AI 适配度 | 15% | 能做成清单/步骤/对比卡片吗？ |
   | 变现路径 | 10% | 1000 粉之后能接什么？ |

3. 选总分最高的那个，定 **3 个固定栏目**（例如：工具测评 / 实操教程 / 踩坑复盘），轮流发。
4. 先跑 4 周：小红书每周 3 篇、公众号每周 1 篇。看**收藏率**和**涨粉**决定是否调整。

## 5. 如果只能给一个默认建议

**「AI + 你的本职行业」的实操干货卡片**。理由：
- 你已经在搭 AI 工作流，这本身就是素材，写「我怎么用 AI 做 X」天然真实；
- 叠加行业后避开「泛 AI 工具」红海，读者更精准、变现更清楚（咨询/培训/接单）；
- 形式是清单和步骤，最适合本仓库的「长文 → 卡片」流水线，AI 提效最大。
