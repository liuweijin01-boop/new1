## 风险提示
- **小红书自动化有风控风险**：xiaohongshu-mcp 和 Easel 都提醒过。本仓库默认「仅自己可见」+ 人工确认，每天不超过 2–3 篇，不在其他网页端同时登录。
- **公众号接口要 IP 白名单**：家用宽带公网 IP 会变，变了就要去后台更新；或用 wenyan 的远程 Server 模式。
- **AI 内容标识**：《人工智能生成合成内容标识办法》已于 2025-09-01 施行，平台会要求对 AI 生成内容做标识。AI 生成的图片/大段文字发布时按平台提示勾选「含 AI 生成内容」，以真实经历为主、AI 做提效，是最稳的做法。
