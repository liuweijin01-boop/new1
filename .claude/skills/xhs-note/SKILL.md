# 小红书图文

小红书不是公众号的缩写版：**图片承载信息，文案负责共鸣和互动**。

## 1. 卡片 `cards.md`（6–9 页）
- 第 1 页封面：`# 大标题`（≤ 14 字，可用 `<br>` 手动断成 2 行，每行 ≤ 7 字）+ 一行副标题。封面要有明确利益点或反差，例如数字、前后对比、身份代入。
- 第 2 页起每页 **只讲一个点**：`## 小标题` + 3–4 条短 bullet（每条 ≤ 18 字）或一个小表格/引用。
- 最后一页：总结 + 互动问题 / 收藏提示。
- 页与页之间用单独一行 `===` 分隔。
- frontmatter：`theme`（cream / ink / mint，取 profile.md 的偏好）、`author`（小红书昵称）。
- 渲染：`node scripts/render-cards.mjs <dir>/cards.md`。退出码 2 表示有页面溢出，按提示删减后重渲染。然后用 Read 打开 `cards/01.png` 和至少一张内页**自己看一遍**：文字是否可读、有无溢出、节奏是否单调。

## 2. 文案 `note.md`
- frontmatter：`platform: xhs`、`title`（≤ 20 字，含关键词，可带 1 个 emoji）、`tags`（5–8 个：2 个大词 + 3–5 个精准长尾词）。
- 正文 300–600 字：开头一句戳痛点或说结果 → 用 1️⃣2️⃣3️⃣ 列要点（与卡片呼应，不必全复述）→ 结尾抛一个具体问题引导评论。
- 不放链接、微信号、「私信领取」；不用「最」「第一」等极限词。

## 3. 检查
`node scripts/check.mjs <dir>/note.md`，有 ❌ 必须改；⚠️ 告诉用户由其决定。

## 可选：AI 生图封面
需要氛围感封面（而非文字卡）时，可以安装 `xhs-visual-director-skill`（见 README「可选组件」），或让用户用即梦/豆包/Midjourney 按你给的提示词生成，保存到 `<dir>/images/cover.png` 后在 cards.md 封面页用 `![](images/cover.png)` 引用。
