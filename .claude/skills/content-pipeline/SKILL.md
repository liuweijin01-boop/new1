# 一条龙流水线

按顺序执行，**每个阶段结束都停下来给用户看产物并等待确认**，用户可以随时说"跳过"或"改一下"。

0. 读 `profile.md`。关键字段为空 → 先走 `content-strategy`。
1. **选题** → 按 `topic-research` 技能：给 Top 3，用户选定，生成 `brief.md`，并把需要用户补充的素材问题一次问完。
2. **长文** → 按 `wechat-article` 技能写 `article.md`（用户只发小红书时可跳过，直接从 brief 写卡片）。
3. **小红书** → 按 `xhs-note` 技能写 `cards.md`、`note.md`，渲染图片并自查。
4. **检查** → `node scripts/check.mjs`，汇总 ❌/⚠️。
5. **发布** → 按 `publish` 技能，得到明确确认后才调用发布工具。
6. 最后给用户一个清单：产物路径、发布状态、下一篇建议选题（从选题池里取）。
