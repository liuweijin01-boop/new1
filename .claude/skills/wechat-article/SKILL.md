# 公众号长文

## 输入
`content/<dir>/brief.md` 与 `profile.md`。brief 里「需要用户补充的素材」若还没回答，先问用户，不要自己编。

## 结构（1500–3000 字）
1. **标题**：给 5 个备选（≤ 30 字更佳），类型混搭：结果型、反常识型、清单型、提问型、身份代入型。让用户选。
2. **开头 3 段内**交代：这篇写给谁、能得到什么、为什么值得信（用户的经历/数据）。
3. **正文**：3–5 个小标题（`##`），每节 = 观点 + 具体例子/步骤 + 一句可截图的金句（用 `>` 引用或加粗）。
4. **结尾**：一句总结 + 一个评论区问题，引导留言；可选「关注后回复 XX 领取」——仅当用户确实有资料。
5. frontmatter：`platform: wechat`、`title`、`author`、`digest`（≤120 字）、`cover`（默认 `./cards/01.png`，即小红书封面；也可让用户提供）。

## 文风
- 遵守 `profile.md` 的语气；第一人称、短段落（手机上每段 ≤ 4 行）。
- 禁用套话：在当今时代、众所周知、总而言之、赋能、抓手、让我们一起、深度剖析、不难发现。
- 每 300–500 字配一张图的位置，用 `![说明](./images/xx.png)` 占位，并在文末列出「配图清单」供用户补图或用卡片截图。

## 收尾
写完运行 `node scripts/check.mjs <dir>/article.md`，把结果告诉用户。
