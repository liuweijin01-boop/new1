# 《光年之外》60 秒动画短片

一位研究系外行星的天文学家，在排除了 1,844 颗"宜居带"候选星球后，最后一个通过全部条件的候选，是作为基准对照组的地球。全片无台词、无旁白、无结论字幕，把追问留给观众。

- 成片：`out/光年之外.mp4`（1920×1080，2.39:1 遮幅，24fps，60 秒，含配乐与音效）
- 风格锚点：丹尼斯·维伦纽瓦（巨物尺度、低饱和灰蓝、克制固定机位）
- 主情绪：惊（敬畏）；情绪曲线：平缓中一次爆发
- 载体：候选行星清单（开场网格被红叉划掉 → 计数器只剩 2 → 巨幕上 1,844 个红点围着唯一的绿点）

## 风格卡

| 项 | 设定 |
|---|---|
| 三色板 | 主色低饱和灰蓝／辅色冷调黑／点缀色屏幕冷绿 + 警示红 |
| 布光 | 屏幕冷光为主实用光源，侧打人物形成轮廓光；窗外星光为背景辅光；全片无暖色 |
| 运镜 | 固定为主，仅三处动态：镜 3 横移拉开、镜 4 推近、镜 11 拉远揭示 |
| 质感 | 数字低照度、胶片颗粒、暗角、冷光尘埃 |
| 负向约束 | 不要高饱和、不要暖黄、不要环绕/升降/快速变焦、不要人物正面对白特写 |

## 制作方式

整片由代码逐帧生成，不依赖任何生成式视频平台：

- `film.js` — Canvas 程序化绘制全部 14 个镜头（行星表面为三维噪声逐像素渲染，人物为带轮廓光的剪影）
- `audio.py` — numpy 合成配乐与音效（持续音、和声、钟音、盖章、键盘、读数），卷积混响
- `timeline.py` → `timeline.json` — 画面与声音共用的事件时间轴，保证每个红叉与盖章声同帧
- `render.cjs` — 用无头 Chromium 逐帧截取画布，管道送入 ffmpeg
- `render_all.sh` — 4 路并行渲染 → 拼接 → 混入音轨，输出 `out/光年之外.mp4`

依赖：Node 22 + playwright（Chromium）、Python 3 + numpy、ffmpeg、文泉驿正黑与 DejaVu Sans Mono 字体。

```bash
./render_all.sh
# 单帧预览
NODE_PATH=$(npm root -g) node render.cjs stills /tmp/stills 10.5,45.0,58.9
```
